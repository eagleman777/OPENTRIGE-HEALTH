# Contributing to OpenTriage Health

We welcome contributions to make frontline diagnostics more accessible!

## Pull Request Process
1. Fork the repository and create a feature branch: `git checkout -b feature/your-feature-name`
2. Ensure your code passes local linting.
3. Update the README.md with details of changes if applicable.
4. Submit a Pull Request targeting the `main` branch.

## Development Standards
* **React Native:** Use functional components and TypeScript strict mode.
* **FastAPI:** Ensure all new endpoints include Pydantic type validation and Ed25519 signature checks.
